# Airline Data Visualisation

A Python project focused on exploring airline-related data and communicating findings through charts and a written report.

## Contents
- Jupyter notebook for exploratory analysis
- Dataset files used in the analysis
- Exported chart images
- PDF report

## Tools
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## Run the analysis
1. Clone this repository.
2. Install the libraries imported by the notebook.
3. Open the notebook in Jupyter and run its cells in order.
4. Review the exported charts and PDF report for the visual results.
